# gfx-demo

The project behind the README's demo video: one anime.js scene, `scenes/showcase` (1920×1080, 60 fps, 38 s, synth
sound cues), with its storyboard and the `studio` style preset. It is an ordinary gfx project.

```
cd examples/gfx-demo
gfx dev showcase                         # live preview
gfx still showcase --t 16                # one frame
gfx render showcase --audio              # out/showcase/showcase.mp4 + showcase.sound.mp4
```

Open it in gfx studio (Open folder… → this folder) to see the layers, cues and code links.
